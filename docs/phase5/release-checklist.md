# Phase 5 release sequence and evaluation

1. Review Issue #6, ADR, API contract, SQL SHA-256 and the actual hosted Phase 3 inventory. Confirm no Phase 4 dependency is needed, and obtain explicit owner approval for the standalone forward migration. Rehearse on a representative isolated copy first. Keep the four new rollout flags false during migration and application deployment.
2. Deploy the reviewed API and mobile/web bundle only after the existing Phase 3 path (discovery, request, accept, messages, history/cancel) is healthy. Restart API with schema readiness verified. Enable `CASTLY_ADVANCED_SEARCH_ENABLED` for a small internal cohort, then `CASTLY_SMART_MATCHING_ENABLED`, `CASTLY_AI_RECOMMENDATIONS_ENABLED`, and `CASTLY_AI_ASSISTANCE_ENABLED` independently. The recommendations gate exposes deterministic matching even though the external provider remains disabled. No Google checkout or notification toggle changes are part of this phase.
3. Observe bounded route failures, query plans, p95 latency, request-limit rejections, empty results and `unknown` availability proportions without recording campaign prose, identifiers or private documents. Evaluate a reviewed, consented set of campaigns for hard-filter violations (target zero), relevant top-three coverage, missing-data honesty, stability across pagination and no popularity or protected-trait preference. Human review must distinguish a creator-supplied portfolio label from verified capability. A live provider requires separate privacy, cost, retention/deletion and output review before configuration.
4. On a regression, disable the affected flag and restart; leave consented data intact for owner-controlled withdrawal and a separately reviewed retention/deletion plan. Never silently change budget units or assume an unconfirmed day is free. Re-run Phase 3 smoke checks after rollback.

The local demo is client campaign description → local parse → edit and confirm constraints/budget unit → shortlist from published eligible creators with explicit date declaration → editable brief → factual comparison. Native Android/iOS device behavior, hosted Supabase catalog equivalence, actual production latency and any live AI provider have not been validated. No migration, deployment, EAS build, Google Play action or production flag activation occurred.
