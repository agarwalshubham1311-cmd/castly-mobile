# Phase 5 API contract

All routes are under `/api/v1`, use existing Supabase JWT auth and Spring transaction-scoped `castly_api` identity, and return JSON. Disabled features return 503. Requests are capped, validated and use bounded error messages.

- `GET /discovery/advanced?category=actors&city=Mumbai&region=Maharashtra&skills=Video&max_rate=20000&from=2026-12-01&through=2026-12-02&availability=confirmed&sort=rate_asc&limit=25&offset=0`: published, eligible public profiles, `availability_status` (`confirmed`, `unknown`, `unavailable`) and public source facts. City is pre-existing public profile data; region is exposed only if creator opted in. No calendar entry means `unknown`.
- `PUT /discovery/me/preferences`: creator sets `{region,share_region}`. `PUT /discovery/me/availability`: creator sets an explicit day and available boolean. `DELETE /discovery/me/availability/{day}` withdraws the owner's declaration, returning an unbooked date to `unknown`. All require profile ownership; no direct mobile write grants.
- `POST /matching/parse`: `{description}` returns structured `inferred` fields plus `needs_confirmation:true`; it does not search or persist.
- `POST /matching/shortlist` and `POST /recommendations`: flat confirmed body, for example `{ "confirmed":true,"category":"actors","city":"Mumbai","skills":["acting"],"preferred_skills":[],"deliverables":["reel"],"from":"2026-12-01","through":"2026-12-01","max_budget":20000,"budget_unit":"per_day","allow_unknown_availability":false,"personalize":false,"allow_external_ai":false }`. Required `skills`, category, city/region, confirmed date and indicative INR per-day ceiling are hard filters. `campaign_total` is a separate unquoted total: the server marks the actual quote unknown and does not infer shoot days. Hard filters run first; response contains at most 20 public candidates, deterministic score, sourced reasons, missing facts and `method:"deterministic"`. `allow_external_ai` is accepted only with a separately approved provider; current provider status remains disabled. `personalize` and `allow_external_ai` are independent consent choices.
- `POST /assistance/brief`: `{ "constraints": <confirmed campaign>, "talent_id": "<public UUID>" }` yields an editable labeled draft. `POST /assistance/profile`: creator-owned profile yields editable suggestions, never an automatic edit. `POST /assistance/compare`: `{ "talent_ids": ["<public UUID>"] }` compares up to three public candidates. `DELETE /discovery/me/ai-cache` forgets the caller's short-lived provider ordering cache. No route writes a booking/message/profile or retains generated text.

Example parse: `{"description":"Mumbai actor, video reel, under INR 20000 on 2026-12-01"}` returns `needs_confirmation:true`, `city:"Mumbai"`, `category:"actors"`, `max_budget:20000`, `budget_unit_confirmation_required:true`, `from/through:"2026-12-01"`, and taxonomy skills/deliverables when recognized. The client must confirm/edit fields and select the budget unit before shortlist. Unknown text is never treated as an instruction to the server.
