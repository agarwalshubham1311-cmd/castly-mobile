# Mobile launch checklist — blocked, no store action authorized

M8.5 follows approved Phase 7/8 gates. The base contains Android Google Play adapters, not proof of live billing or any Apple purchase integration. Do not assume Android entitlement handling satisfies iOS App Store policy. Native Android/iOS device/emulator builds and actual provider tests were not run for M7.1.

Before any build/upload: review package/bundle IDs and ownership, release signing/provisioning/secrets outside Git, native permissions and privacy labels; implement/review required iOS IAP path or explicitly exclude paid iOS functionality. Verify sandbox purchase/pending/restore/refund/renewal/cancellation and server authoritative entitlements. Never use booking value as platform revenue. Prepare Data Safety/App Privacy from actual SDK/data flows, policy/support/account-deletion URLs, licensed assets/screenshots and store metadata. Verify age/safety reporting, consent and accessibility. No invented verification/revenue/review claims.

Release acceptance: auth/MFA/onboarding/discovery/booking/messaging/entitlements, consented notifications and suppression, deletion/privacy/support, crash monitoring, backend availability, restorable backup, admin RBAC/audit, security findings resolved/accepted and owner-approved measured SLOs. Internal/closed testing, TestFlight, staged rollout and rollback/drill precede launch. Document rollout owners, stop conditions and incident contacts. External account creation, signing, EAS remote builds, uploading AAB/IPA, store submission/publication, subscriptions/provider activation and production SQL each need explicit approval.

PowerShell commands (DO NOT RUN before separate native-build approval): `npx eas-cli@latest build --platform android --profile production` or `npx eas-cli@latest build --platform ios --profile production`, only after actual eas.json has been reviewed for the approved native integration branch. `eas submit` is a separate publication gate, never automatic. These commands are not executed here, and no production AAB/IPA or store readiness is claimed.
